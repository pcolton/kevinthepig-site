# Kevin the Pig — site

Public pages for the Kevin the Pig iOS app, served by GitHub Pages at https://kevinthepig.com:

- `index.html` — landing page
- `privacy.html` — privacy policy
- `support.html` — support and how to play
- `terms.html` — terms of use
- `app/` — kevinthepig.com/app, the link shared prints carry: redirects directly to the App Store, including without JavaScript
- `og-image.png` — link-preview artwork; update its version query in `index.html` when changing it
- `site.js` — the landing page's download bar, shown whenever the hero's App Store button is off screen
- `style.css` — the scrapbook look (kraft paper, taped instant prints, sticky notes), light and dark
- `media/` — screenshots and videos from the app's `marketing/app-store/1.0/`, sized for the web, and Apple's App Store badges (toolbox.marketingtools.apple.com, unmodified)

The icon and the sticky-note colours come from the app's editions.
